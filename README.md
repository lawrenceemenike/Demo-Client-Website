# O&O Partners - Homepage Prototype

A modern, clean, and professional one-page homepage prototype for **O&O Partners** (Chartered Accountants & Business Advisors), built for deployment on Netlify.

## Overview
- **Headline**: *“Practical accounting, audit and business advisory for organisations navigating change.”*
- **Practice Areas**:
  - Assurance and Advisory
  - Consulting
  - Insolvency and Corporate Recovery
  - Financial and Management Consulting
  - Tax and Corporate Compliance
- **Design Specifications**:
  - Pure white background with warm-stone card accents.
  - Color palette based on evergreen forest green (`#0F4030`, `#145943`) and warm amber/ochre (`#D97706`).
  - Zero traces of blue, purple, magenta, or cyan.
  - Fully responsive mobile-first layout with native Netlify form support.

## Project Structure
- `index.html`: Complete one-page prototype with inline CSS, SVGs, and interactive logic.
- `netlify.toml`: Netlify deployment configuration and security headers.
- `LICENSE`: Repository license.

## Netlify Deployment
Connect this repository directly to Netlify or deploy via Netlify CLI:
```bash
netlify deploy --prod --dir="."
```
